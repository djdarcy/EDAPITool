## What the sweep taught

- **Presence is not behaviour.** Every first-round test asked whether a declared flag *appeared*; none asked what it *did*. Three of the four killable survivors were that gap.
- **A guard in the conftest can hide a guard in the code.** The store test was green under a mutant that removed the very exemption it was written for, because the autouse fixture had already turned the write off.
- **The fixture had no row for the flag to decide.** Same class as slice 2's fingerprint anchor: the test data did not contain the case.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** No mutant touched the `append` kind or `metavar`; both are exercised only by the settlement plugin's declaration in unit 2.
