## Triage

| Survivor | Verdict | Reasoning | Killing test |
|---|---|---|---|
| R2 | killable — **a gap that predates the move** | every reader test builds its grid with `make_grid`, which pads three blank rows after the data, so the final grid row was never a commodity; and the last live row is a zero-need commodity nobody asserts on. The first killer I wrote missed it for the same reason and survived; the second cuts the grid so its final row is the last commodity | `test_a_commodity_on_the_final_grid_row_is_read` |
| W3 | **equivalent** for every reachable state | a format range is always one cell `{marker_column}{row}` with `row` in `[first_data_row, last_data_row]`, and `plan.updates` always carries `marker_range(last_data_row)` spanning exactly those cells, so the updates check passes only when every format cell would. The check is a fence for a renderer whose formats stray, and stays | — (`equivalents.md`) |
