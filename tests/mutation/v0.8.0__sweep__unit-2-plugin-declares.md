## What the sweep taught

- **Declared is not driven.** Five layout words, two proven. The same shape as unit 1's "presence is not behaviour", one level down.
- **A default is only visible from the install that lacks the word.** Both M13 and M14 are defaults for a plugin that does not declare the flag, and every serve test loaded the one plugin that does.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** No mutant touched a help string or the `append` flag's metavar.
