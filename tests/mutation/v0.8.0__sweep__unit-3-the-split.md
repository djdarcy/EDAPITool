## What the sweep taught

- **A filter has two sides.** The resolvers were proven to find the plugin that offers and to return None when nobody does; the third case, something that *looks* like an offer, had no module to show it. The generator, which did not know the test modules, attacked the one word no fixture exercised.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** No mutant touched `_NoLayout`, the `_target_name` choice between destination and binder, or the stock file's header text.
