## What the sweep taught

- **Two mutants found nothing new but say what the tests hold.** M07 (a bare `plugins` dispatching into a plugin named None) died on `test_list_is_still_the_listing`, and M12 died on both the refusal test and the safe-command test -- the `and` between "not enabled" and "not safe" is held from both sides.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** No mutant touched the `SystemExit` translation (a plugin's own argparse exiting), the listing's column width, or the usage line.
