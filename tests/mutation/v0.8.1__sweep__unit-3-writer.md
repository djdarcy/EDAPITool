## What the sweep taught

- **A fake that pads its answers hides the API's real shape.** Every worksheet fake in the suite returned `[[value]]` for a single cell. The real API returns `[]` for an empty one, and the code's `rows and rows[0]` guard existed for exactly that case, untested until a mutant removed it.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.**
